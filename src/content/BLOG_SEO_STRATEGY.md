## Internal Linking Strategy

### Hub-and-Spoke Model
Each blog post should link to:
1. **2-3 related blog posts** (peer links)
2. **Homepage directory** (/) - main CTA
3. **Relevant directory detail pages** (/directory/[slug]) - when mentioning specific platforms

### Internal Link Matrix

| From Post | Links To |
|-----------|----------|
| Product Hunt Guide | Hacker News, Reddit, Indie Hackers, BetaList |
| Hacker News Guide | Product Hunt, Reddit, Indie Hackers, BetaList |
| Reddit Guide | Product Hunt, Hacker News, Indie Hackers, BetaList |
| Indie Hackers Guide | Product Hunt, Hacker News, Reddit, BetaList |
| BetaList Guide | Product Hunt, Indie Hackers, Hacker News, Reddit |

### Link Anchor Text Guidelines
- **Exact match:** Use sparingly (1-2 times per post)
- **Partial match:** Preferred (e.g., "Reddit marketing strategy" instead of just "Reddit")
- **Natural context:** Links should flow naturally within sentences
- **Avoid:** Generic anchors like "click here" or "read more"

### Required CTAs Per Post
1. **Primary CTA (Newsletter):** Add newsletter signup mention where relevant
2. **Secondary CTA (Directory):** Link to homepage directory (/)
3. **Continue Reading Section:** Add at end of each post with related article links

## Content Structure Guidelines

### Title Formula (SEO-Optimized)
```
[Platform] [Action] [Year]: [Benefit/Data Point] ([Hook])
```

**Examples:**
- "Product Hunt Launch Strategy 2025: How to Get Featured (Only 10% Make It)"
- "Reddit Account Warmup Guide: How Much Karma Do You Need? (Real Data)"

### Meta Description Formula (155-160 characters)
```
[Data-driven/Complete/Evidence-based] [topic] guide. [Key benefit 1], [key benefit 2], [key benefit 3]. [Unique value prop].
```

### H1 Guidelines
- Should match or closely reflect the SEO title
- Include primary keyword
- Include year for freshness (2025)
- Include data point or hook in parentheses

### Content Structure
1. **Hook** (first 2-3 paragraphs) - Include primary keyword naturally
2. **Data/Evidence** - Tables, statistics, case studies
3. **Actionable Sections** - How-to steps with clear headers
4. **Comparisons** - vs. other platforms (internal link opportunities)
5. **FAQ Section** - Target long-tail keywords as questions
6. **Continue Your Launch Strategy** - Internal links section
7. **CTA** - Newsletter signup prompt

## Keyword Research Process

### Tools to Use
1. **Ahrefs/SEMrush** - Keyword difficulty and volume
2. **Google Search Console** - Current ranking keywords
3. **Google Autocomplete** - Long-tail opportunities
4. **Reddit/Quora** - User questions as keyword targets

### Target Metrics
- **Keyword Difficulty:** <20 (low competition)
- **Search Volume:** 100-1,000 monthly (long-tail sweet spot)
- **Search Intent:** Informational or commercial investigation

### Keyword Placement Priority
1. **Title/H1** - Exact match primary keyword
2. **First paragraph** - Natural inclusion
3. **H2 headings** - Secondary keywords
4. **Meta description** - Primary + secondary keywords
5. **Body content** - Natural distribution (avoid stuffing)
6. **Image alt text** - Descriptive with keyword where relevant
